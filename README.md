# KaloriVision AI (ön sürüm 0.1)
Türkçe, mobil öncelikli, ücretsiz PWA: kalori/besin takibi, barkod (Open Food Facts), fotoğraftan yemek tanıma (cihazda CLIP), su, kilo, istatistik.
Kurulum: `npm install --ignore-scripts && npm run build` → `dist/` klasörünü yayınla (GitHub Pages "branch" yayını). Geliştirme: `npm run dev`.
Veriler yalnızca cihazda (IndexedDB). Gizli anahtar gerektirmez. Reklam (AdMob) APK aşamasında Capacitor ile eklenecek.
